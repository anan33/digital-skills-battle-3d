# معركة المهارات الرقمية 3D — مشروع Android

هذا المشروع يغلّف لعبة HTML الأصلية داخل تطبيق Android باستخدام Capacitor 6.

## ما الذي تم تجهيزه؟
- نقل اللعبة الأصلية إلى `www/index.html`.
- تحويل استدعاء Three.js إلى مسار محلي `www/vendor/three.min.js`.
- إزالة رابط Google Fonts الخارجي حتى لا يطلب التطبيق الخط من الإنترنت.
- إضافة إعداد Capacitor وهوية التطبيق.
- إضافة GitHub Actions لبناء APK تجريبي تلقائياً.

## رفع المشروع إلى GitHub
1. فك ضغط ملف ZIP.
2. افتح GitHub وأنشئ مستودعاً جديداً باسم `digital-skills-battle-3d`.
3. ارفع **محتويات المجلد** إلى المستودع (وليس ملف ZIP نفسه).
4. تأكد أن `package.json` و`capacitor.config.json` ومجلد `.github` و`www` ظاهرة في الصفحة الرئيسية للمستودع.
5. افتح تبويب **Actions** ووافق على تفعيل GitHub Actions إذا طُلب ذلك.
6. شغّل سير العمل **Build Android APK** عبر **Run workflow**، أو ادفع Commit جديداً إلى فرع `main`.

## تنزيل APK
بعد نجاح عملية البناء:
1. افتح نتيجة التشغيل في تبويب Actions.
2. انزل إلى قسم **Artifacts**.
3. نزّل `digital-skills-battle-debug-apk.zip` وفك ضغطه.
4. ستجد `app-debug.apk`، ثم انقله إلى هاتف Android وثبّته.

## ملاحظات مهمة
- هذا إصدار Debug للتجربة والتثبيت اليدوي، وليس إصداراً منشوراً على Google Play.
- اللعبة وملفاتها الأساسية مضمّنة محلياً، ولذلك لا تحتاج إلى اتصال أثناء اللعب.
- تم تعطيل تحميل خط Cairo من Google Fonts لتجنب طلب الإنترنت؛ سيستخدم الجهاز خطاً عربياً متاحاً كبديل. يمكن إضافة ملف خط محلي لاحقاً إذا رغبت بالحفاظ على شكل Cairo.
- أول عملية بناء عبر GitHub تحتاج اتصالاً بالإنترنت لتنزيل حزم npm وAndroid Gradle؛ هذا لا يعني أن التطبيق يحتاج الإنترنت بعد تثبيته.
- لم أغيّر منطق اللعبة أو أسلوب اللعب عمداً.
